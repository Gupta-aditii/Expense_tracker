# Expense Tracker

## About
A web-based expense management application.

## Technologies
- Python
- Flask
- SQLite
- SQLAlchemy
- HTML
- CSS
- Chart.js

## Features
- Add expenses
- Edit expenses
- Delete expenses
- Search expenses
- Filter by category
- Filter by date
- Expense statistics
- Category-wise analysis
- Expense visualization

## How to Run

1. Clone the repository
2. Create virtual environment
3. Install dependencies
4. Run app.py
5. Open localhost:5000
